# Offline NASA sample (LOCAL_NASA_SAMPLE)

`msl_curiosity/` holds gzip-compressed, unmodified copies of 24 public REMS and RAD products from the NASA Planetary Data
System (sols 238–243, about 4.6 MB). They are the offline fallback for the Phase 1–2 telemetry pipeline and are used in tests.

These files are **public NASA/PDS source data**. They are not owned by DEEPSIFT and are **not** covered by the DEEPSIFT
Apache-2.0 code licence. Each file's original PDS URL and SHA-256 are in `msl_curiosity/MANIFEST.json`; provenance and
attribution are in the repository `NOTICE`.
